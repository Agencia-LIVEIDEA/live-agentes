# live-criacao

Skills do time de **Criação**: produção criativa com IA.

**Dono:** time Criação no GitHub (`@Agencia-LIVEIDEA/criacao`). Ele revisa e aprova as mudanças nesta pasta.

## Skills

| Skill | O que faz |
| --- | --- |
| `human-image` | Direção fotográfica e render de imagens (stills, product shots, anúncios estáticos). |
| `human-motion` | Reels e motion graphics: imagem-base, animação, pacing e MP4 final. |
| `human-cinematic` | Produção cinematográfica: roteiro, character sheets, frames por cena e vídeo. |
| `human-carrossel` | Carrosséis de Instagram em escala, de notícias ou de tema próprio. |
| `human-social` | Desdobra texto + imagens em peças nativas para Instagram e LinkedIn. |
| `human-dna` | DNA criativo de uma marca: identidade, tom de voz, sistema visual. |
| `human-team` | Squad de agentes criativos, da ideia ao handoff. |

As skills `human-*` geram imagem e vídeo pelo Higgsfield CLI ou pelo Magnific MCP. Cada pessoa precisa da própria conta e chave nessas ferramentas.

**Pendente:** confirmar se a licença das skills `human-*` permite o uso pelo time todo.
