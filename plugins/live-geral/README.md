# live-geral

Base que **todo o time** da Live Idea instala: skills e agentes que servem a qualquer departamento.

**Para quem:** todo o time. Mudanças entram por pull request e são aprovadas pelo Martech.

## Skills

| Skill | O que faz |
| --- | --- |
| `memoria-projeto` | Lê e registra a memória comum dos jobs (repositório `live-memoria`), em três níveis: agência, cliente e projeto. |

## Agentes

Nenhum ainda. Agentes ficam em `agents/<nome-do-agente>.md`. Use o modelo em `_modelos/agente/`.

Um agente é um especialista que o Claude chama para fazer uma parte do trabalho em separado (revisar um texto, pesquisar um tema, conferir uma planilha) e devolve só o resultado.
